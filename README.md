# ЛУНЬ · интерактивный литературно-музыкальный постер

Цифровой постер: обложка книги слева, а от неё идёт линия электропередачи с треками, подвешенными на проводах.
Провода колышет ветер, наведение щипает их как струну, а по проводу к книге бежит ток.
Под названием книги сменяются цитаты персонажей, а в углу щёлкает дозиметр.
Фон параллаксит вслед за курсором.

Стек: **React 18 + JavaScript + Vite + CSS + SVG**. Без backend, БД, авторизации и тяжёлых библиотек.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка и предпросмотр production-версии:

```bash
npm run build
npm run preview
```

## Публикация

Постер выкладывается на GitHub Pages автоматически: при каждом пуше в ветку `main`
workflow `.github/workflows/deploy.yml` собирает проект и публикует папку `dist`.
Сборка идёт с относительными путями (`base: './'`), поэтому работает в подпапке вида `/music-poster/`.

Превью ссылки в Telegram берётся из `public/og-image.jpg` (1200×630) и мета-тегов в `index.html`;
полный адрес сайта подставляется при сборке из переменной `SITE_URL`.
Telegram кэширует превью: после замены картинки обновить его можно через бота @WebpageBot.

## Как поменять содержимое

Правки нужны только в `src/data/posterData.js`:

- `title`, `meta`, `accent` — тексты и акцентный цвет книги;
- `quotes` — цитаты персонажей. Добавляются через `said('Персонаж', 'цитата', 'ещё цитата')`,
  кавычки вокруг текста ставит вёрстка. Цитаты сменяются сами, наведение или кнопка паузы их останавливает,
  нажатие на имя оставляет только цитаты этого персонажа;
- `attachQuotes(треки, [['начало названия трека', 'цитата'], …])` — цитата из книги к каждому треку.
  При наведении на трек она появляется в его окошке и, когда ток доходит до обложки, под названием книги.
  На обложке такого трека стоит знак «». Опечатка в названии выводит предупреждение в консоль;
- `cover` — изображение обложки (импорт из `src/assets/covers/`);
- `track(название, исполнитель, альбом, год, обложка, источник)` — композиция. Обложка — файл
  в `public/covers/` (путь вида `/covers/имя.jpg`). Источник:
  `{ provider: 'spotify', trackId, yandex: { trackId, albumId } }` (Spotify с запасным Яндексом)
  или `{ provider: 'yandex', trackId, albumId }`; ID берутся из ссылки на трек;
- `backgroundImage` — путь к фоновому изображению (файл в `public/images/`).

Шрифт заголовков — Oswald из пакета `@fontsource-variable/oswald`: он собирается вместе с проектом
и работает без интернета. Заменить его можно в переменной `--font-display` в `src/styles/global.css`.

## Отрывки треков

Звук идёт через встраиваемые плееры сервисов, ключи и backend не нужны.
Основной плеер — Spotify: на телефонах он грузится заметно быстрее виджета Яндекс Музыки.
У 37 треков есть запасной плеер Яндекса: под плеером в окошке есть кнопка
«Не играет? Включить через Яндекс Музыку», и выбор запоминается в браузере (пригодится там,
где Spotify недоступен). «Santana Medley» от vibermx есть только на Яндексе и играет оттуда.

- Наведение на трек открывает окошко и запускает отрывок, уход курсора закрывает его и глушит звук.
- Клик или тап закрепляет окошко; закрыть можно крестиком, `Esc` или кликом мимо.
- Браузеры запрещают звук до первого действия на странице: до первого клика плеер
  показывается без автозапуска, с подсказкой в окошке.
- Отрывок начинается с начала трека: выбрать другое место встроенные плееры не дают.
- Обложки альбомов лежат в проекте и видны без интернета, но сам звук идёт из сервисов.

## Поведение и адаптив

- Переключение книг: стрелки у обложки, клавиши `←` / `→`, на телефоне — свайп по обложке.
  Открытая книга записывается в адрес страницы, поэтому ссылкой вида `…/#freon` можно поделиться.
- Дозиметр в правом нижнем углу щёлкает тем чаще, чем ближе курсор к треку. Щелчки нарезаются из записи
  настоящего счётчика `public/sounds/dosimeter.mp3` (громкость — `VOLUME` в `src/lib/geigerClicks.js`).
  Звук включается кнопкой и запоминается, файл скачивается только после включения; пока играет отрывок,
  дозиметр молчит. На сенсорных экранах и узких окнах он скрыт.
- Геометрия линии считается из реальных размеров поля и обложки при смене книги, ресайзе
  и через `ResizeObserver`, поэтому провода всегда доходят до обложки и точек подвеса.
- ≥ 861px — двухколоночная композиция: обложка слева, справа линия из трёх проводов
  (на узком окне проводов становится четыре, чтобы треки не сталкивались).
- ≤ 860px — композиция складывается в столбец, опоры скрываются, треки висят списком на одном кабеле.
- При `prefers-reduced-motion` провода и треки неподвижны, искры тока скрыты,
  цитаты не печатаются и не сменяются сами.
  На тач-устройствах параллакс отключается.
